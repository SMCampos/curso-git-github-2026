git init . – Transforma a pasta em um repositório Git
rm -rf .git/ - excluir uma pasta/repositório GIT

Configurar variáveis de usuário
git config --global user.email “sandrocampos72@gmail.com”
git config --global user.name "SMCampos"


git status – mostra o status do repositório
git add – adiciona o que vai ser enviado para o commit
git commit -m “mensagem do commit” – criar um commit
